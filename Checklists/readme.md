# Чек-лист тестирования Swag Labs (SauceDemo)

**Проект:** Тестирование интернет-магазина
**Автор:** Денис Сигаев
**Назначение:** Быстрая проверка ключевой функциональности перед релизом / smoke- и регрессионное тестирование

---

## 1. Авторизация (Login)

- [ ] Успешный вход с валидными данными (standard_user)
- [ ] Вход под каждым тестовым пользователем (problem_user, performance_glitch_user, error_user, visual_user)
- [ ] Ошибка при неверном пароле
- [ ] Ошибка при пустых полях username / password
- [ ] locked_out_user не может войти, показывается корректное сообщение
- [ ] Логин чувствителен к регистру
- [ ] Поле password скрывает вводимые символы
- [ ] После успешного входа открывается страница Inventory

---

## 2. Каталог товаров (Inventory)

- [ ] На странице отображаются все 6 товаров
- [ ] У каждого товара отображаются название, цена, изображение и кнопка добавления
- [ ] Сортировка Price (low to high) работает корректно
- [ ] Сортировка Price (high to low) работает корректно
- [ ] Сортировка Name (A to Z) работает корректно
- [ ] Сортировка Name (Z to A) работает корректно
- [ ] Клик по названию/изображению товара открывает корректную карточку товара
- [ ] Кнопка "Add to cart" добавляет товар и меняется на "Remove"
- [ ] Кнопка "Remove" убирает товар и возвращается в состояние "Add to cart"
- [ ] Счётчик иконки корзины обновляется при добавлении/удалении
- [ ] Изображения товаров соответствуют их названиям

---

## 3. Карточка товара (Product detail)

- [ ] Открывается корректная карточка выбранного товара
- [ ] Отображаются название, описание, цена и изображение
- [ ] Кнопка "Add to cart" работает с этой страницы
- [ ] Кнопка "Back to products" возвращает в каталог
- [ ] Состояние кнопки (Add/Remove) синхронизировано с каталогом

---

## 4. Корзина (Cart)

- [ ] Иконка корзины открывает страницу Cart
- [ ] Все добавленные товары отображаются с корректным названием и ценой
- [ ] Кнопка "Remove" удаляет товар из корзины
- [ ] Счётчик корзины обнуляется, когда все товары удалены
- [ ] Кнопка "Continue Shopping" возвращает в каталог
- [ ] Кнопка "Checkout" переводит на шаг "Your Information"
- [ ] Корзина пуста после успешного оформления заказа

---

## 5. Оформление заказа (Checkout)

- [ ] Шаг "Your Information": обязательность полей First Name, Last Name, Zip Code
- [ ] Понятные сообщения об ошибках при незаполненных полях
- [ ] Кнопка Cancel на шаге Information возвращает в Cart
- [ ] Шаг Overview: отображается корректный список товаров и их количество
- [ ] Item total совпадает с суммой цен товаров в заказе
- [ ] Tax рассчитывается корректно
- [ ] Total = Item total + Tax
- [ ] Кнопка Cancel на шаге Overview возвращает в Cart
- [ ] Кнопка Finish завершает заказ и показывает "Thank you for your order!"
- [ ] Кнопка "Back Home" возвращает в каталог

---

## 6. Меню навигации (Menu)

- [ ] Бургер-меню открывается по клику
- [ ] Меню закрывается кнопкой "X"
- [ ] Пункт "All Items" возвращает в каталог из любого раздела
- [ ] Пункт "About" открывает внешний ресурс
- [ ] Пункт "Logout" завершает сессию
- [ ] Пункт "Reset App State" очищает корзину и сбрасывает сортировку

---

## 7. Выход из системы (Logout)

- [ ] После логаута происходит переход на страницу входа
- [ ] Поля логина пустые после выхода
- [ ] Прямой переход на внутренние страницы (/inventory.html и т.д.) без авторизации невозможен
- [ ] Кнопка "Назад" в браузере после логаута не восстанавливает сессию

---

## 8. Кросс-браузерность и общее UI

- [ ] Сайт корректно отображается в Chrome
- [ ] Сайт корректно отображается в Firefox
- [ ] Сайт корректно отображается в Edge
- [ ] Верстка не ломается при изменении размера окна браузера
- [ ] Ссылки в футере (Twitter/X, Facebook, LinkedIn) кликабельны и открываются
- [ ] Нет "битых" изображений и иконок (кроме тестовых пользователей с намеренными багами)
- [ ] Нет ошибок в консоли DevTools на основных страницах (standard_user)

---

## 9. Тестовые пользователи (специфичное поведение)

- [ ] problem_user — зафиксированы и задокументированы известные дефекты (изображения, навигация, добавление/удаление, checkout)
- [ ] error_user — зафиксировано поведение при сортировке и оформлении заказа
- [ ] visual_user — зафиксированы визуальные отличия от эталона
- [ ] performance_glitch_user — зафиксирована задержка при входе
