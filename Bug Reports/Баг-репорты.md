# Баг-репорты для Swag Labs (SauceDemo)

**Проект:** Тестирование интернет-магазина
**Автор:** Денис Сигаев
**Сайт:** https://www.saucedemo.com/
**Окружение:** Chrome (последняя версия), Windows 10 / 11
**Всего багов:** 10 (Critical: 3, High: 3, Medium: 3, Low: 1)

---

## BUG-01. Оформление заказа невозможно завершить для problem_user

| Поле | Значение |
|---|---|
| **Модуль** | Checkout |
| **Пользователь** | problem_user |
| **Severity** | Critical |
| **Priority** | High |
| **Предусловия** | Авторизован как problem_user, товар добавлен в корзину |
| **Шаги воспроизведения** | 1. Перейти в Cart → Checkout<br>2. На странице "Your Information" ввести First Name<br>3. Попытаться ввести значение в поле Last Name |
| **Ожидаемый результат** | Поле Last Name принимает ввод, форма заполняется полностью, доступен переход Continue |
| **Фактический результат** | Поле Last Name не реагирует на ввод текста, заполнить его невозможно |
| **Комментарий** | Так как поле обязательно для заполнения, пользователь этого сегмента не может завершить покупку ни при каких условиях — блокер основного бизнес-сценария без обходного пути |
